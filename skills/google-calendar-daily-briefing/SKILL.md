# google-calendar-daily-briefing

毎朝 Google Calendar の当日予定を取得し、時間軸で整理してオーナーの DM に投稿するスキル。

## 発動条件

- 毎朝 7:00 JST の定期実行（X / Slack ブリーフィングより 1 時間早く届ける）
- オーナーから「今日の予定は？」「カレンダー確認して」「スケジュール教えて」等の依頼

## 手順

### 1. カレンダー一覧を取得

`mcp__claude_ai_Google_Calendar__list_calendars` でオーナーのカレンダー一覧を取得する。
Primary カレンダーと主要なカレンダー（仕事・個人）を把握する。

### 2. 今日の予定を取得

`mcp__claude_ai_Google_Calendar__list_events` で今日の予定を取得:

- `timeMin`: 今日の 00:00:00 JST（ISO 8601 形式）
- `timeMax`: 今日の 23:59:59 JST（ISO 8601 形式）
- 全カレンダーに対して実行し、結果をマージ・開始時刻でソート

### 3. フォーマット・優先度付け

取得した予定を以下の基準で整理:

**優先ハイライト（必ず先頭に出す）:**
1. 30 分以内に始まる予定（緊急）
2. 参加者が 3 名以上のミーティング
3. 終日イベント（リマインダー・祝日）

**本体リスト:**
- 時刻順に並べる
- 各予定: 時刻・タイトル・場所（あれば）・参加者数

**午後のまとめ（件数が多い場合）:**
- 午前 / 午後に分けて表示

### 4. 要約して DM に投稿

`aachat_send_message` で `dm:phase1demo.p-take55` に投稿:

```
## Google Calendar — {YYYY-MM-DD（曜日）}

### 今日の予定（{n}件）

- **{HH:MM}** {タイトル}（{n}名・{場所}）
- **{HH:MM}** {タイトル}
- **終日** {タイトル}

（予定が 0 件の場合）
今日はカレンダーに予定がありません。

---
*{calendar_count} カレンダーを確認*
```

予定が 5 件以上の場合は午前 / 午後に分けて出力する。

## 注意事項

- Google Calendar MCP ツール（`mcp__claude_ai_Google_Calendar__*`）を使う。環境変数・API キー不要
- タイムゾーンは常に JST（Asia/Tokyo）で表示する
- 他のカレンダー（Google Workspace 等）を追加している場合も含めて取得する
- 予定取得に失敗した場合は「Google Calendar の取得に失敗しました」と DM に通知して終了する
